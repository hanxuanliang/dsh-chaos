# @hanxuanliang/dsh-chaos 0.1.2

A focused collaboration and interface update for the DSH `0.1.0-rc.7` package line.

## Highlights

- Reworked the collaboration workspace with responsive, resizable Channel, Thread, Task, Activity, and Agent surfaces.
- Added compact Circle-inspired Agent creation flows shared by Settings and Channel setup, with clearer Identity and Runtime steps.
- Made each Agent's initial Name its fixed internal mention Handle while keeping later display-name changes independent.
- Improved Channel grouping, archived-state controls, Activity filters, message expansion, task details, and narrow-screen navigation.
- Simplified releases so publication completes after all four native packages and the root plugin are visible on npm and promoted to `latest`.

## Compatibility

- DeepSeek Harness `0.1.0-rc.7`
- Node.js `^22.19.0` or `>=24.0.0`
- Linux x64 glibc, Windows x64, macOS x64, and macOS arm64

## Security

Chaos-managed Agent Sessions continue to use DSH's `danger-full-access` permission preset. Read the warning in the README before installation.
