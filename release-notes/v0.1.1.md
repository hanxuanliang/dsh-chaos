# @hanxuanliang/dsh-chaos 0.1.1

The first public preview of durable peer collaboration for DeepSeek Harness.

## Highlights

- Stable Agent identities, Charters, managed Workspaces, and DSH runtime bindings.
- Durable Channels, Threads, Messages, Deliveries, Tasks, and Activity state.
- Responsive DSH-native collaboration UI with Channel lifecycle management.
- Prebuilt native modules for Linux x64 glibc, Windows x64, macOS x64, and macOS arm64.

## Compatibility

- DeepSeek Harness `0.1.0-rc.7`
- Node.js `^22.19.0` or `>=24.0.0`

## Security

Chaos-managed Agent Sessions currently use DSH's `danger-full-access` permission preset. Read the warning in the README before installation.
